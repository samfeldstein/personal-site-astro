# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Sam Feldstein’s personal site (samfeldstein.xyz): plain HTML, CSS and JavaScript (no framework, no build step), served as Cloudflare Workers static assets. No Worker script, no forms. Ported from Astro in October 2026, following the Presswork rebuild (`~/presswork`); the plan is `docs/plain-html-plan.md`, but where it differs from the code, the code is right. Open items are in `ISSUES.md`.

## Commands

All scripts are dependency-free Node except `photos.mjs` (`sharp`, `exiftool-vendored`; `npm install` first).

- `node sync.mjs`: writes the shared parts into every page, inlines CSS, stamps script links, regenerates the sitemaps (`--check` writes nothing and exits 1 if anything is out of date)
- `node check.mjs`: fails if the site has drifted or something is broken
- `node --test test/*.test.mjs`: tests that `check.mjs` catches what it should
- Before any commit: `node sync.mjs && node check.mjs && node --test test/*.test.mjs`
- `npx wrangler dev`: local preview (`npm run dev:phone` listens on the local network)
- Deploys: Cloudflare Workers Builds runs `npm run build` (`projects.mjs`, then `sync.mjs --check` + `check.mjs`) on every push, so any drift fails the deploy and the Code page's project list is refreshed from GitHub.
- `node projects.mjs`: rewrites the Code page's project list between `<!-- projects -->` markers from the public GitHub repositories of samfeldstein (no forks, archived, private or profile repos; newest first; `GITHUB_TOKEN` optional). If GitHub can't be reached it warns and leaves the list as is. Descriptions lose characters outside the font subset. Tested in `test/projects.test.mjs`.
- **New year:** the copyright year comes from sync (`{{year}}`). `sync.mjs --check` still accepts last year's, so deploys keep working on January 1; run `node sync.mjs` and commit early in the year.

## Architecture

- **`site/`** is deployed as is (`wrangler.jsonc`: `assets.directory` `./site/`, `not_found_handling` `404-page`). Pages: `index.html`, `code/`, `photos/`, `published-writing/` and `404.html`. The 13 résumé pages are disabled and kept in `_archive/resumes/` (not deployed, synced or checked; see `ROADMAP.md`); the PDFs in `site/static/resumes/` are still served. Pages use root-relative paths, so they need a server.
- **`shared/`** holds the single sources: `head.html`, `skip-link.html`, `copyright.html`, `endmatter.html` (the epigraph page and colophon page at the end of every page, including the quote script; it holds the `credit`, `lighthouse` and `copyright` blocks, which sync fills after it), `credit.html` (the colophon text), `lighthouse.html` (written by `lighthouse.mjs`), `running-head.html` (the "Ever in Flux" link at the top of inner pages), `facts.json` (site name and description, emails, `allowedHosts`, `sizeBudgetKB`) and `css/`. Each page starts with a `<!-- page: {...} -->` comment (`title`, `description`, `css` list, `fonts` to preload, `typefaces` named in the colophon, `noindex`). `sync.mjs` writes the shared blocks between `<!-- shared:... -->` markers, inlines `base.css` plus the page’s `css` list into one `<style>` (comments stripped), adds `?v=` hashes to `/js/` links, and writes `sitemap-index.xml` and `sitemap-0.xml`. **Never edit text between `shared:` markers**; edit `shared/` or the page comment and run sync.
- **Styling**: `shared/css/base.css` (reset, view transition), `book.css` (the shared book theme: Cormorant Garamond faces, paper and ink tokens, headings, `.toc` leaders, `.ornament`, `.running-head`, `.chapter` opener, `.book-page`; historical ligatures only in epigraphs and the colophon), plus the shared list-of-works styles (`ol.works`: title with dotted leaders to a short date, then an indented italic source and small-caps type), used by Published Writing and the Code projects alike; then one file per page where needed (`home`, `photos`, `code`, `404`; `resume` and `resume-print` serve only the archived résumés). Pages list `["book"]` plus their own file, if any, in their `css`. Colors are `light-dark()` tokens.
- **Book theme** (October 2026): the whole site reads as a book. Home is the cover, then a contents page (chapters 1–3 match Published Writing, Photography, Code), an epigraph and a colophon. Inner pages are chapters with a running head and a "Chapter N" opener: Published Writing as a list of works, Photography as a borderless justified mosaic (rows of equal height, each photo at its own aspect ratio via `--r` on each item and flex-grow; title and month on hover or focus, hidden from screen readers since the alt text already names the photo) with a full-screen `<dialog>` lightbox (`site/js/gallery.js`: no frame, previous/next fixed to the screen edges so they don't move between photos, arrow keys, Esc or a click outside the photo to close, focus back on the thumbnail; each thumbnail is also a plain link to the full image without JS), Code as a list of works plus the epigraph and colophon, and the 404 as an erratum slip. Everything is set in Cormorant Garamond, subset from the Google Fonts source with all OpenType features kept (small caps, old-style figures, historical ligatures) plus curly quotes, dashes and the fleuron ❦; license in `site/static/fonts/licenses/`. The files are `cormorant-garamond-2.woff2` and `-italic-2` (renamed when ↗ was added, because fonts are cached as immutable). External links get a small ↗ from `book.css` (on the entry name for leader lists, on the publication for Published Writing), announced as ", external". Email links get a small envelope (a CSS mask, since the font has no envelope glyph), announced as ", email". Fontsource builds strip those features, so re-subset from the source with `pyftsubset` if the font changes. Don't animate the cover's opacity: Lighthouse then finds no LCP and scores performance 0.
- **Fonts** are self-hosted under `site/static/fonts/` with `unicode-range` subsets and `size-adjust` local fallbacks. They’re cached as immutable, so a changed font needs a new file name. `check.mjs` fails on any character outside the shipped ranges (add a `facts.json` `allowedChars` list only for characters that should fall back on purpose). `cormorant` and `noto-sans` remain only for the archived résumés.
- **Gallery**: source JPGs in `photos/` (not deployed). After adding, removing or re-captioning a photo, run `npm install`, then `node photos.mjs`: it reads Title, Description (the alt text) and CreateDate with ExifTool, generates missing WebPs in `site/img/photos/`, deletes orphans, and rewrites the gallery between `<!-- gallery -->` markers in `site/photos/index.html`, newest first. Then sync, check, commit.
- **Lighthouse panel**: `node lighthouse.mjs 98 "0 ms" "1.5 s" "2.3 s"` (score, blocking time, speed index, time to interactive, from a mobile Lighthouse run) writes `shared/lighthouse.html`, shown in every colophon; with no numbers it calls PageSpeed Insights (`PSI_KEY` env var). Then sync, commit, deploy. Current numbers are from a local run on 2026-10-17.
- **Scripts**: `site/js/quote.js` is an ES module holding the quotes array and the generator (loaded by the end matter on every page; shows the first quote on localhost). Script files load as `type="module"`; classic inline scripts (the prefetch fallback in `head.html`) are wrapped in a self-calling function. `check.mjs` enforces both.
- **`check.mjs`** verifies sync is current, one `<h1>` and `<main id="main-content">` per page, unique ids and id references, alt text, links and asset paths (page links end in `/`), CSS syntax, emails against `facts.json`, font coverage, robots.txt, no moving masks, module scripts, no hosts outside `allowedHosts`, and the gzipped size budget.
- **Caching and URLs**: `site/_headers` (fonts and `/js/` immutable, images shorter) and `site/_redirects` (old URLs to `/code/` and `/photos/`).

## Rules

- **Keep the book theme consistent.** New pages are chapters built from `book.css`; put shared pieces there rather than copying them between page files.
- **Code page skills** are one plain-text line of names separated by commas, with no "and" before the last one, even when skills are added.
- **Project names** come from GitHub repository names; to show a different name, add the repository to `NAMES` in `projects.mjs` (Postoley Dance Ensemble and Digital Notebook are there).
- **No third-party hosts.** Nothing loads from a host outside `allowedHosts`; plain `<a>` links to other sites are fine.
- **Comments:** almost none in shipped CSS and JS. Keep the structural markers (`<!-- page: -->`, `<!-- shared:... -->`, `<!-- gallery -->`, `<!-- projects -->`). Don’t add explanatory comments.
- Git history is still about 480 MB from the old committed Astro image cache; rewriting it is optional and the owner’s call.
